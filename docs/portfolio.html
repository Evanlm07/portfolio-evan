Création et mise en ligne de mon portfolio

Un site personnel qui présente mon parcours et mes compétences, versionné avec Git et publié avec GitHub Pages.

Du 10/10/26 au 22/10/26

Le site

Adresse : evanlm07.github.io/portfolio-evan. Une page en HTML, CSS et JavaScript : présentation, parcours, stages, compétences et contact, avec des animations (fond réseau animé, frise du parcours, terminal).

Publication

  1. Fichier index.html dans un dossier ouvert dans VS Code.
  2. Initialisation du dépôt Git, configuration de user.name et user.email, premier commit.
  3. Publication sur GitHub en dépôt public (portfolio-evan).
  4. Activation de GitHub Pages : branche main, dossier racine.

Mise à jour

Chaque modification suit le même cycle : modifier, enregistrer, Commit avec un message clair, puis Sync Changes. Le site se met à jour en une minute environ. Exemple : passage au thème « bleu nuit ».
